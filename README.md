# FPGA SPI Emulator Docs

The documentation lives in the readable Markdown files under `site/`.

Run a local preview:

```sh
npm start
```

Eleventy writes the finished static website to `_site/` when you run:

```sh
npm run build
```

Edit a page in `site/*.md`. The shared navigation and HTML structure are in
`site/_includes/layouts/docs.njk`, and the shared styles are in `assets/styles.css`.
